# Cyber Sentinel - Enterprise Security Suite

Professional GUI tool for Network Scanning, Auto-Fix, and Optimization.

## Features
- Network Scan & Deep Port Analysis
- Vulnerability Detection (Firewall, SSH, Telnet)
- One-Click AUTO-FIX System
- Internet Speed Optimizer

## Install (Linux)
sudo apt install python3-nmap python3-psutil -y
pip3 install --break-system-packages customtkinter
sudo python3 pro_security_gui.py

## Windows
Download EXE from Releases or Windows-Release folder.
